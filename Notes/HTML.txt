History of MangoDB:
===================
MangoDB was created by Eliot and Dwight in 2007,
when they faced scalability issues.
while working with relational database.

the organization that developed MangoDB was originally known as 10gen.

In Feb 2009, they changed their business model and released MangoDB as an open source project.

the organization changed its name in 2013 and now know as MangoDB Inc.

Features of MangoDB:
===================
1. MangoDB provides high performance.
Most of the operations in the MangoDB are faster compared to relational databases.
2. MangoDB provides auto replication features.
that allow you to quickly recover data in case of a failure
3. Horizontal scaling is possible in MangoDB because of sharing.
sharding is partitioning of data and placing it on multiple machines in such a way that the order of the data is preserved.

constructor:

	constructor is a special member method. it is used to initialize object values.

types of constructor:

	1) default constructor or null constructor
	2) argument or parametarized constructor
	3) copy constructor
	4) overloading constructor (polymorphism)


rules of constructor:
=======================

	*) classname and constructor name should be equal.
	*) constructor should not be private access
	*) constructor has no return type (ie. dont use void)
	*) constructor called at the time of object creation.

inheritance:
============
	The mechanism of deriving derive class from the old one is known as inheritance.

	purpose: reusability of code

types of inheritance:

1) single inheritance
	only one base class and only one derive class is known as single inheritance.

2) multiple inheritance
	more than one base class and only one derive class (java does not support multiple inheritance so we can use interface concepts in next chapter)

3) multilevel:
	more than one level .

4) hierarchical inheritance:
	it is tree format : only one base class and more derive class.

5) hybrid inheritance:
	combination of any two inheritance.

PID தெரிந்த process-a terminate panna.
Suppose:
PID = 1234
Then:
kill 1234
Force kill
kill -9 1234
⚠️ kill -9 forceful. Normal kill work aagala na mattum use pannradhu better.
23. killall
Process name வைத்து terminate panna:
killall firefox
⚠️ Same name-la multiple processes irundha multiple processes affect aagalam.

24. nice
Process priority set panna.
Example:
nice -n 10 command
Example:
nice -n 10 myprogram
25. renice
Already running process-oda priority change panna.
renice 10 -p 1234
Here:
10   → nice value
1234 → PID
